# KomandDok для Android

Версия 1.4. Установите `KomandDok-Android.apk`. Это пробная сборка для Android 7.0+ с актуальным Android System WebView, arm64-v8a и x86_64. APK подписан отладочным ключом, распространяется отдельно от Google Play.

1. Откройте меню и нажмите «Новая командировка». Заполните карточку и сохраните её.
2. На вкладке «Расходы» внесите суммы или выражения. Суточные и аванс при желании подставляются из заявки.
3. На вкладке «Печать и чеки» нажмите «Добавить чеки». Можно выбрать сразу несколько изображений или PDF. Подготовьте формы и соберите комплект.
4. При сборке комплекта приложение показывает проценты и номер файла. В свёрнутом приложении сборка продолжается, а в шторке отображается прогресс и затем «PDF готов». На Android 13 и новее для уведомлений нужно [разрешение](https://developer.android.com/develop/ui/compose/notifications/notification-permission).
5. В предпросмотре доступны «Печать», «Поделиться» и «Сохранить PDF». В общий комплект включаются PDF и поддерживаемые изображения: JPG, PNG, WEBP, BMP и TIFF.

Карточки и вложения находятся в закрытом хранилище приложения. Для отправки или резервной копии готового документа сохраните PDF в «Файлы». Удаление приложения или очистка его данных удаляет локальные карточки. Синхронизации с Windows и автоматического переноса поездок нет. Приложение не запрашивает доступ в интернет.

Сборка из исходников: Java 17, Android SDK 35 и Python 3.13; `gradlew.bat :app:assembleDebug :app:lintDebug`. APK создаётся в `app/build/outputs/apk/debug`. Если на Windows Gradle не открывает loopback с ошибкой `PipeImpl`, укажите через `JAVA_TOOL_OPTIONS` свой короткий существующий путь без пробелов, например `-Djdk.net.unixdomain.tmpdir=C:/tmp`.

Веб-интерфейс основан на настольном KomandDok, с мобильной разметкой в `android.css` и мостом `android.js`. `adapt_web.py` заново переносит HTML/JS из корня этого репозитория. Python-модули в `app/src/main/python` используются локально через Chaquopy без сервера. В Android-версии предпросмотр рисует системный PDF-рендерер, а экспорт и печать работают через стандартные средства Android.

Проверка движка: `python app/src/main/python/smoke_mobile.py` с установленными Flask, Pillow, ReportLab и pypdf. Для подключённого устройства есть тестовый APK (`gradlew.bat :app:assembleDebugAndroidTest`); после установки двух APK запустите `adb shell am instrument -w ru.j701.trips.test/ru.j701.trips.SmokeRunner`.
