КомандДок. Переносимая версия для Windows x64.

ЗАПУСК
Дважды нажмите J701.exe. Откроется браузер и появится анимированный утёнок в трее.
Python, Word и Excel для работы не нужны. Установка и права администратора не требуются.
Консольные окна при запуске не открываются.

ПАПКИ РЯДОМ С EXE
Данные/Командировки — карточки поездок и история введённых вариантов.
Данные/Корзина — удалённые проекты, которые можно восстановить.
Данные/settings.json — предпочитаемый порт (по умолчанию 20866).
Данные/запуск.log — журнал запуска и ошибок.
Печать — документы, чеки и готовые комплекты по поездкам.
Если этих папок или файла настроек нет, программа создаёт их при запуске.
Существующие данные при этом сохраняются. Если удалить данные самостоятельно,
программа создаст пустые папки, но не сможет восстановить удалённые файлы.

ПЕРЕНОС
Сначала остановите сервер, затем копируйте папку программы целиком.
Никакие рабочие файлы не хранятся по абсолютному адресу исходного компьютера.
При запуске EXE внутренние библиотеки временно распаковываются средствами сборки;
карточки поездок и чеки всегда остаются рядом с EXE.
Папка программы должна быть доступна для записи — например, Документы или флешка.

ОСТАНОВКА
Кнопка «Остановить сервер» в браузере или пункт меню значка в трее.
Нажатие на утёнка открывает приложение. Закрытие вкладки оставляет трей работать.
Повторный запуск EXE открывает уже работающий экземпляр.

ОБНОВЛЕНИЕ
Остановите сервер и замените только J701.exe. Папки Данные и Печать сохраняйте.

Во вкладках «Расходы» и «Служебная записка» можно указать свои даты.
На вкладке «Печать и чеки» можно загрузить образец подписи сотрудника
в PNG или JPEG для текущей поездки. Приложение уберёт фон бумаги, обрежет
поля и покажет, как выглядит подпись. Подписанные формы создаются отдельно.
В комплект включается отмеченный вариант; формы идут перед чеками.

В предпросмотре «PDF с подписью» нажмите «Настроить подпись». Положение
и размер сохраняются отдельно для каждой формы и применяются в новых поездках.
Не распаковывайте поверх своих данных архив с чужими карточками поездок.

СЕТЬ
Приложение работает на этом компьютере без внешних сервисов.
Основной порт 20866; при занятости выбирается следующий свободный.
Используются только порты от 20000 и выше.

СБОРКА ИЗ ИСХОДНИКОВ
Исходный проект хранится отдельно в папке TripAssistant.
Из его папки Данные: python build_portable.py
Для сборки нужны зависимости из requirements.txt и PyInstaller.
