# Командировки

Запуск: двойной щелчок по `Командировки.py` в папке программы. Откроется браузер. Повторный запуск открывает уже работающее приложение. Нужен Python 3.10 или новее. Библиотеки при необходимости устанавливаются автоматически при первом запуске, для этого нужен интернет. Дальше приложение работает без интернета, Word и Excel не нужны.

1. Заполните город, даты и сотрудника. Проверьте три формы ФИО и адресата. Суммы на первой вкладке — план для заявки.
2. На вкладке «Расходы» введите фактические суммы: проезд, отель, суточные, такси, прочее. Допускаются выражения `227 + 502 + 707` и `800 * 5`. Подробные строки расходов необязательны и **прибавляются** к простому калькулятору: не указывайте один чек в обоих местах.
3. Если нужна отдельная служебная записка, заполните её сумму и назначение либо свой текст. Общие реквизиты берутся из карточки.
4. На вкладке «Печать и чеки» выберите нужные формы и нажмите «Подготовить документы». По умолчанию авансовый отчёт печатается в двух экземплярах. Отдельный PDF отчёта содержит один экземпляр, дублирование выполняется при сборке комплекта.
5. Добавьте чеки кнопкой либо через Проводник. Проверьте документы по ссылкам в списке. Галочками выберите файлы, стрелками задайте порядок, рядом — число копий. Нажмите «Собрать PDF для печати», откройте полученный PDF и напечатайте через Ctrl+P. Ничего не отправляется на принтер автоматически.

Внутри папки программы создаётся `Печать`. В ней для каждой поездки создаётся папка с датой, городом и коротким идентификатором. Подпапки «Документы» и «Чеки» содержат формы и вложения; общий PDF сохраняется в корне поездки. Файлы можно положить также в корень или свои подпапки. После этого нажмите «Обновить из папки». Имя папки поездки после создания остаётся постоянным, даже если исправить город или даты.

Поддержка общей печати: PDF, JPG, PNG, WEBP, BMP, TIFF. У изображения сохраняются пропорции, учитывается ориентация камеры, оно помещается на A4. Все страницы многостраничного TIFF сохраняются. Зашифрованный PDF с паролем нужно сначала разблокировать самостоятельно. DOC/XLS и другие форматы можно хранить и скачать, но для общей печати их нужно самостоятельно сохранить в PDF. Максимум загрузки за один раз — 200 МБ.

Сохранение карточки выполняется кнопкой «Сохранить»; перед загрузкой чеков и подготовкой документов программа сохраняет карточку сама. При закрытии с несохранёнными правками браузер предупреждает. После изменения карточки нажмите «Подготовить документы» заново. Уже собранные комплекты — исторические файлы: они не меняются и не включаются в следующий комплект автоматически.

Образцы пользователя использованы как ориентир содержания и реквизитов; исходные DOC/XLS не копируются и не редактируются. Формы самостоятельные, чёрно-белые, A4, с Times New Roman и местами для подписей. В авансовом отчёте отдельно показаны возврат остатка и перерасход к возмещению. Это простая форма по образцу пользователя, а не унифицированная форма АО-1. Расшифровка расходов при необходимости печатается отдельно.

## Структура для доработок

- `app.py` — HTTP API, сохранение карточек, вложения, подготовка комплекта.
- `domain.py` — поля карточки, проверка данных, точный денежный калькулятор на Decimal.
- `printing.py` — самостоятельные PDF-формы и сборка PDF/изображений.
- `templates/index.html` — разметка интерфейса.
- `static/app.js`, `static/style.css` — поведение и тёмная тема.
- `Командировки/*.json` — сохранённые поездки; `defaults.json` — последние реквизиты.
- `tests/test_app.py` — проверки расчётов, сохранения и печати.
- `запуск.log` — журнал запуска и ошибок.

Резервная копия: скопируйте папку программы целиком, включая подпапку `Печать`. Для переноса между компьютерами нужны обе папки. Путь к папке печати вычисляется относительно программы. Для изменения бланков редактируйте `printing.py`; для добавления категории — `CATEGORIES` в `domain.py` и `categories` в `static/app.js` и распределение строк в отчёте.

Приложение слушает только `127.0.0.1, порт по умолчанию 20866`. Код не обращается к внешним сервисам. Если порт занят, точка входа выбирает следующий свободный (в пределах 100 портов). Все порты от 20000 и выше. Предпочитаемый порт задаётся в settings.json; runtime.json запоминает работающий экземпляр. Остановить сервер можно кнопкой в приложении, через меню иконки в трее или Ctrl+C в терминале VS Code. Для ручного запуска и диагностики: из папки «Данные» выполнить `python app.py`; для проверки — `python -m unittest discover -s tests -v`.



## Обновление интерфейса и управление сервером

Единственная точка входа — `Командировки.py` в корне. Откройте папку TripAssistant в VS Code, выберите этот файл и нажмите Run Python File либо запустите в терминале из корня:

```powershell
python .\Командировки.py
```

Запуск идёт в одном процессе. Кнопка «Остановить сервер», пункт меню в трее «Остановить сервер и выйти» и Ctrl+C завершают сервер и убирают значок. Обычное закрытие вкладки оставляет сервер и трей работать. Левое нажатие на значок открывает утилиту; правое — меню. Повторный запуск открывает уже работающий экземпляр. Рисунок иконки хранится в static/app.png и static/app.ico; исходник утёнка и кадров — work/draw_duck_icon.py. Управление сервером и треем — runtime.py.

Города и цели поездок выбираются из выпадающих подсказок в полях. Можно ввести свой вариант. Сохранённые варианты записываются в Командировки/history.json; история сохраняется и после изменения карточки. В целях заранее доступны «участия в партнерской конференции» и «выезда на объект клиента».

В новых карточках аванс по умолчанию равен итогу заявки, суточные — плановым суточным. Переключатели «Из итога заявки» и «Суточные из заявки» поддерживают связь при последующих изменениях плана. Снимите переключатель, чтобы ввести фактическую сумму вручную. Для ранее созданных карточек ручные суммы сохраняются, связь можно включить самостоятельно.

На каждой вкладке есть «Предпросмотр» и «Печать». Первые три вкладки открывают соответствующий бланк, последняя — выбранный комплект с чеками. Предпросмотр отображает страницы независимо от PDF-плагина браузера; печать открывает стандартный диалог браузера. В нём отключите колонтитулы и выберите A4. Оригинальный PDF доступен по ссылке в окне предпросмотра. Копии авансового отчёта учитываются при сборке комплекта; для отдельной печати число копий задаётся в диалоге принтера.

Кнопка «Открыть папку» запускает Проводник Windows с папкой выбранной поездки. У сохранённой карточки для этого не требуется сохранять текущие правки. У новой карточки сначала должны быть заполнены обязательные поля.


Иконка J701: жёлтый утёнок с покачиванием и морганием. В трее кадры обновляются каждые 130 мс; при остановке сервера поток анимации завершается. В интерфейсе используется static/app.gif, для статической иконки вкладки — static/app.ico. Ник J701 есть на значке, в заголовке приложения и подсказке трея.


При остановке через трей или браузер все открытые вкладки автоматически показывают экран «Приложение закрыто» с указанием способа остановки. При потере соединения появится сообщение о недоступности сервера. Несохранённые данные остаются в текущей вкладке и доступны для скачивания в JSON. После повторного запуска нажмите «Обновить после запуска». Шапка заявки и служебной записки сдвинута на 9,9 мм вправо; для старых PDF заново подготовьте документы.


Меню сворачивается стрелкой вверху слева; состояние запоминается в браузере. В компактном режиме доступны создание поездки и остановка сервера. На экране закрытия оставлены только статус и кнопка обновления страницы.


Карандаш рядом с проектом открывает управление: переименование, открытие карточки, создание копии и удаление в корзину. Название проекта не меняет город и печатные документы. Копия содержит поля и расходы без вложений. При удалении карточка и вся папка поездки переносятся в Данные/Корзина. Кнопка «Корзина» в боковом меню позволяет восстановить проект с файлами; безвозвратного удаления в интерфейсе нет.



Портабл-сборка находится в соседней папке J701_Portable. Запуск — J701.exe; исходники для доработки остаются в TripAssistant. В переносимой версии Python и библиотеки встроены в EXE. Данные, Корзина и Печать создаются рядом с EXE автоматически. Сборка: python build_portable.py из папки Данные (PyInstaller и зависимости должны быть установлены).
